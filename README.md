# 🤖 Rule-Based AI Python ChatBot

A simple **Rule-Based AI Chatbot** developed using Python.  
The chatbot interacts with users through the command line and provides predefined responses based on keywords detected in the user's questions.

---

## 📌 Project Overview

This project demonstrates how a basic chatbot can be created using Python without using external AI APIs or Machine Learning models.

The chatbot:

- 👋 Greets the user according to the current time.
- 👤 Takes the user's name.
- 💬 Responds to basic questions.
- 🧠 Uses a predefined dictionary as chatbot memory.
- 🔍 Detects keywords in user messages.
- 🔄 Continues the conversation until the user types `bye`.

---

## 🚀 Features

### 👋 Time-Based Greeting

The chatbot checks the current system time and displays:

- Good Morning
- Good Afternoon
- Good Evening
- Good Night

It also uses the user's name while greeting them.
